Formação de Palavras

O objetivo é praticar a combinação de sílabas para formar palavras utilizadas no cotidiano.



1. Junte as sílabas

CA + SA formam qual palavra?

2. Complete a palavra

Qual sílaba completa a palavra BO__?

LA ME RI

3. Organize as sílabas

Qual palavra é formada pelas sílabas JA - NE - LA?

4. Forme uma palavra

Qual palavra é formada pelas sílabas PA - NE - LA?
